# Artificial Neural Networks
A collection of academic projects and assignments developed as part of the **Artificial Neural Network** course.

This repository contains implementations and experiments covering various fundamental neural network algorithms and learning methods. The projects were recreated and organised to improve code structure, readability, and maintainability while preserving their original academic objectives.

## Projects
- Hebb Rule Algorithm
- Perceptron Algorithm
- Delta Rule Algorithm
- Backpropagation Algorithm
- Adaline - Madaline Algorithm
- Kohonen - SOM Algorithm
- LVQ Algorithm
- Rainfall Forecasting using Backpropagation

Detailed explanations, implementation notes, and usage instructions are provided in the README of each project.

## Topics Covered
The projects cover several fundamental concepts in artificial neural networks, including:
- Supervised learning
- Unsupervised learning
- Classification
- Pattern recognition
- Function approximation
- Time-series forecasting
- Neural network training and weight optimisation

## Technologies
- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
